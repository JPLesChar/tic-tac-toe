# Tic Tac Toe

A mobile-friendly two-player Tic Tac Toe game. Players take turns on the same device; share the link to invite someone to play.

## Run it

Open `index.html` in a browser, or publish the repository with GitHub Pages.

## Publish with GitHub Pages

1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the `main` branch and `/ (root)` folder, then click **Save**.
4. Wait for the deployment to finish. Your game will be available at `https://jpleschar.github.io/tic-tac-toe/`.
5. Open that link on your phone and tap **Share on WhatsApp** (or copy and paste the link into a chat).

GitHub Pages may take a few minutes to publish the first time.
